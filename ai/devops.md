# DevOps

## Роль

Консультує щодо Maven, статичного аналізатора SpotBugs, пакування (shade), Maven Wrapper і GitHub Actions.

## Обмеження

Конфігурацію (pom.xml, ci.yml) студент перевіряє й має пояснити кожен запис; Maven Central у середовищі розробки недоступний, тому справжню збірку підтверджує лише CI.

## Промпт

Перевір вимоги до POM, Maven Wrapper, JAR і GitHub Actions. Склади чек-лист для `test`, `verify`, `package` та матриці Windows/macOS/Ubuntu. Поясни кожен крок і назви можливі помилки на кожній ОС.
